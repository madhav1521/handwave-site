HandWave Privacy Policy

Effective date: October 5, 2026

HandWave is a Chrome extension that lets users interact with webpages using hand gestures captured through their device camera.

Camera and hand tracking

When gesture tracking is enabled, HandWave requests webcam access and processes the camera stream locally on the user's device to detect hands and supported gestures.

Camera frames, hand landmarks, and gesture results are not uploaded to a HandWave server, sold, or shared with third parties.

The extension does not record or permanently store webcam footage.

Stored settings

HandWave uses Chrome's chrome.storage API to store extension settings, including user preferences and site-specific settings.

Local processing

The hand-tracking runtime, WebAssembly assets, and hand landmark model required by HandWave are bundled with the extension and run locally.

Permissions

  • offscreen — runs camera access and hand tracking in an offscreen extension document.
  • storage — saves HandWave settings.
  • tabs — identifies the active tab/site for site-specific settings and browser navigation functionality.
  • activeTab — accesses the tab the user is currently viewing so HandWave can apply site-specific settings and deliver gesture events to that page.
  • <all_urls> — allows HandWave's content script to provide gesture functionality on webpages.

Changes

This policy may be updated if HandWave's functionality or data practices change.

Contact

For privacy questions, open an issue on the HandWave site repository.
